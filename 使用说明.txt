========================================
  Dock  v1.12 ——  Windows 桌面 Dock 栏
========================================

原生 C++ / Direct2D 实现，单文件绿色版，无需安装。
空闲 CPU ≈ 0%，专用内存 ≈ 60 MB，静止时 0 帧渲染，不影响游戏与日常使用。


【一、怎么运行】
  1) 把整个文件夹放到一个「可写」的位置，例如：
        桌面\Dock、D:\Tools\Dock、U 盘根目录
     ※ 不要放在 C:\Program Files 下，否则无法保存配置。
  2) 双击 Dock.exe 即可，托盘会出现 Dock 图标。
  3) 首次运行 Dock 是空的，只有时间、九宫格和「＋」，添加应用后即可使用。
  4) 如想开机自动启动：右键托盘图标 → 勾选「开机自启」。


【二、添加 / 删除应用】
  · 添加（三种方式，任选）：
      1. 把 exe / 快捷方式(.lnk) / 网址(.url) 直接拖到 Dock 上；
      2. 点 Dock 末尾的「＋」，在文件对话框里选择程序；
      3. 右键托盘图标 → 「添加应用…」。
  · 删除：在 Dock 里右键某个图标 → 「移除」。
  · 排序：在 Dock 里按住某个图标左右拖动，松手即保存顺序。
  · 打开：左键单击图标。


【二·五、九宫格设置与日期时间】
  · Dock 右侧有一个九宫格按钮，点一下会弹出 3×3 设置面板。
  · 九格分别是：
      快捷设置 / 系统托盘 / 添加应用
      切换外观 / 图标大小 / 停靠位置
      系统任务栏 / 智能收起 / 全屏隐藏
    每个设置格下方会直接显示当前值（如「透明」「中」「底部」），
    点一下即可循环切换或执行。
  · 关闭面板：按 ESC、再点一次九宫格，或点击面板外任意位置。
  · 面板会自动出现在 Dock 的内侧：底部停靠向上弹、顶部向下弹、左侧向右弹、右侧向左弹。
  · 时间块显示 时:分 + 月日 + 星期；竖排时自动拆成三行，不会截断。
  · 时间只在分钟变化时重绘，不产生每秒刷新。


【三、托盘右键菜单（全部设置都在这里）】
  · 隐藏 Dock / 显示 Dock
  · 位置        → 底部 / 顶部 / 左侧 / 右侧   （竖排自动切换纵向布局）
  · 外观        → 毛玻璃 / 透明 / 深色实心 / 浅色实心
  · 图标大小    → 小(36) / 中(44) / 大(52)
  · 图标倒影    → 开关（Nexus 风格倒影）
  · 隐藏系统任务栏 → 开关
       隐藏后 Dock 会自动沉到屏幕最底部（若停在底部），
       恢复任务栏后 Dock 自动回到原位。
  · 被窗口挡住时自动收起 → 开关（默认开）
       有窗口压住 Dock 时它淡出并彻底从桌面消失，遮挡消失后自动回来；
       想临时用它：把鼠标顶住 Dock 所在的屏幕边缘并停稳约半秒即可唤出，
       唤出后 3 秒不操作会自动收回；鼠标停在 Dock 上会持续续期。
       只是快速划过窗口底部不会误触发，也不会抢走页面下方按钮的点击。
  · 贴边唤出（需停稳） → 开关（默认开）
       关闭后彻底不做边缘检测，鼠标贴边也不会自动唤出（零额外唤醒）。
  · 全屏应用时自动隐藏 → 开关（默认开）
       玩游戏、看全屏视频、演示 PPT 时，Dock 自动隐身，退出全屏自动回来。
       普通窗口、最大化窗口不受影响；任务栏开"自动隐藏"时也不会误判。
       若在全屏里仍想用 Dock：点一下托盘图标即可唤出，本次全屏内它不会再藏。
       关掉这个开关后，程序连检测定时器一并停掉（零周期唤醒）。
  · 开机自启
  · 打开系统托盘
      直接展开任务栏的隐藏图标面板；开启「隐藏系统任务栏」时
      会临时显示任务栏，关闭面板后自动再次隐藏。
  · 添加应用… / 刷新图标 / 打开程序所在文件夹 / 退出

  Dock 空白处右键，同样可以打开这个菜单。


【四、配置文件（都在 exe 同目录，便携，不写注册表）】
  · dock-settings.ini   material=0..3（毛玻璃/透明/深色/浅色）
                        iconSize=36/44/52   edge=0..3（底/顶/左/右）
                        autoStart=0/1       reflection=0/1
  · dock-items.txt      每行一个程序路径，可手工编辑
  ※ 换电脑 / 发给别人时，不要带上这两个文件（里面的路径是原电脑的）。


【五、常见问题】
  · 杀毒软件报毒？
    本程序未做数字签名，部分杀软会对「未签名的小体积 exe」误报，
    可添加信任，或自行用 signtool 签名后分发。
  · 图标不显示 / 是白框？
    .url 网页快捷方式的图标本身就是白底方块，属于文件本身，不是渲染问题；
    可在托盘菜单点「刷新图标」重试。
  · 重启后位置 / 外观变回去了？
    多半是放在了不可写目录（Program Files），换个可写路径即可。
  · 想彻底卸载？
    先退出（托盘 → 退出），再删除文件夹；如开过自启，
    请先在菜单里取消「开机自启」。


【六、已知限制】
  · 多显示器：目前按主屏工作区定位。
  · 毛玻璃模式下，圆角外侧已用窗口区域裁掉，不会露出矩形亮块。
  · 「系统托盘」按钮优先展开 Win11 的隐藏图标面板；老系统会回退到任务栏设置页。

祝使用愉快 :)

【七、关于毛玻璃（Acrylic）】
  · Dock 的"毛玻璃"直接调用 Windows 系统的 Acrylic 材质。
  · 若系统里关掉了「透明效果」，Windows 会拒绝给它模糊，Dock 会自动退回深色实心。
    开启方法：设置 → 个性化 → 颜色 → 打开「透明效果」。
  · 想完全不要底板、图标直接浮在桌面：把「外观」切到「透明」。

【八、为什么全屏游戏里看不到 Dock 了？】
  Dock 默认开启「全屏应用时自动隐藏」：检测到前台窗口铺满整屏且无标题栏
  （典型就是全屏游戏、全屏视频、PPT 放映）时，Dock 会自动隐藏自己。
  退出全屏（Alt+Tab 回桌面）后它自动出现，不需要手动操作。
  想在全屏里也用：点托盘图标唤出；或右键菜单关掉该开关。
